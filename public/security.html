Our Security Commitment

At ICONIK Global, the security of your personal data and account is our highest priority. We employ industry-leading technologies and practices to keep your information safe.

Authentication Security

ICONIK uses Firebase Authentication (Google Cloud) for all user sign-ins. This means:

  • Passwords are hashed and never stored in plain text
  • All authentication traffic is encrypted with TLS/HTTPS
  • Password reset via verified email link
  • Account lockout protection against brute-force attacks

Data Storage Security

All user data is stored in Google Firebase/Firestore, one of the most secure cloud database platforms available. Data is:

  • Encrypted at rest and in transit
  • Protected by Firebase Security Rules (access control)
  • Backed up automatically with geographic redundancy

Media Security

All uploaded images, videos, and documents are stored via Cloudinary with:

  • Secure HTTPS delivery
  • Upload presets that prevent unauthorized file types
  • Content delivery via global CDN

Payment Security

All payments on ICONIK are processed by PCI-DSS compliant third-party providers:

  • Paystack — NGN card, bank transfer, and USSD payments
  • PayPal — International USD payments
  • Cryptocurrency — BTC, ETH, USDT via NowPayments

ICONIK does not store card numbers or payment credentials on its servers.

Access Controls

ICONIK employs a tiered admin system:

  • Chief Admin: Full platform control — single designated account
  • Sub Admins: Limited access to specific communities and features
  • Moderators: Content moderation only
  • Members: Access only to their own data and public content

Reporting Security Issues

If you discover a security vulnerability, please report it responsibly to: iconikglobal01@gmail.com

We take all security reports seriously and will respond within 48 hours.

User Responsibilities

  • Use a strong, unique password for your ICONIK account
  • Never share your login credentials with anyone
  • Log out from shared devices
  • Report suspicious activity or unauthorized access immediately
